# Contribuindo

1. Crie uma branch para a alteração.
2. Não commite `.env`, `node_modules/` ou arquivos `.db`.
3. Mantenha cada funcionalidade dentro do seu módulo.
4. Rode `npm --prefix backend run build` e `npm --prefix frontend run build` antes do commit.
5. Abra um Pull Request descrevendo a alteração.
